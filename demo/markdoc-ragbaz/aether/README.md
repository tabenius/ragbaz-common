# Aether — studies in affection

Three newly authored symbolic templates: Prima materia, Sun and moon, Blackening.
These are contemporary interpretations, not historical facsimiles, recovered
correspondence, scientific findings or claims about a real relationship.

Each package opens with a replaceable original specimen. Open your own Markdown
from Document tools or use `?document=starter.md`; optional `&sha256=<64 hex>`
pins exact bytes under the same bounded, credential-free loading policy as sci.
The rendering contract is embedded and inspectable offline. System fonts are the
default; Typography offers curated Google alternatives only after selection.
No remote images, executable authored SVG or document-selected imports are permitted.

Family navigation offers all three presentations. It changes the template URL,
not the manuscript: it deliberately does not forward a potentially private
`document` parameter. Open the desired document explicitly in the new template.
The symbolic plate is optional; its preference is local and shared by the family.
Appearance offers System/Light/Dark. Blackening is natively dark even with a light
OS preference; explicit Light is available. Other variants follow OS darkness.
Printing always uses light paper; forced-colors suppresses the symbolic artwork.

All plates are original host-owned diagrams with accessible descriptions. Their
marks are poetic and illustrative, not a documented historical symbol glossary.
