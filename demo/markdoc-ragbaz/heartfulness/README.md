# Heartfulness — first proof

A working name for a contemporary, late-Victorian British storybook-inspired
reading surface: pale butter-yellow paper, fine grain, expressive serif titles,
original rose-and-leaf ornaments and a deliberately weathered keepsake mood.
This is not a period reconstruction, a replica of a particular designer's work,
or an affiliation with any organization using the name Heartfulness.

Use the menu to open your own Markdown, or `?document=starter.md`; an optional
`&sha256=<64 hex>` pins exact bytes under the same bounded loading policy as sci.
The default text is a replaceable design specimen, not an actual letter/archive.

Document tools → Dress the page: Plain / A little / Full bloom. Paper grain is
independently optional. Choices persist when storage permits. System/Light/Dark,
source inspection, navigation and the rendering contract remain available.
Print omits the grain and outer frames; forced-colors suppresses decoration.
System fonts are the offline default. Typography offers the host-curated Google
alternative Cormorant Garamond / EB Garamond; selecting it contacts Google, with
system fallback if unavailable. No remote textures, images or executable
document-selected artwork are allowed.
Paper-spread mode omits the outer climbing frame so it cannot cross columns.
Section flourishes remain optional; Plain removes them and the title fleuron.

SVG botanical companions are original host-owned illustrations. Presentation
is separate from prose: loaded Markdown gets the same optional decoration.
Only the first paragraph following a level-one title receives subtitle styling;
documents without an opening title keep their first paragraph as ordinary prose.
Deployment and route ownership belong to the independent meta.ragbaz repository.
